# PARAM_AUDIT addendum: 6 technical keys missing from the audit (2 Nov 2026)

PARAM_AUDIT.md is unchanged. TRACEABILITY.md (scan of the resolved MOST_REALISTIC_AUDITED_LIT_P10 and the global blocks) found 6 config keys that act on MR_P10 and are not in the audit. They are listed here with the same status label. Values are those in `runs/2026-11-02-v12-census/full_audited/config_full_audited.yaml`. Code lines refer to the frozen code `full_audited/code` (CODE_SHA256SUMS). None of these keys changes in any queued run.

Label for all 6: **Authors' assumption (modelling agent's design choice, accepted by the authors)**. No published source gives these values. They are numerical or GIS-processing choices, not claims about Nuragic building.
