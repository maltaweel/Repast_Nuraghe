# Research-agent setup

How the research agent that built and ran this model was configured is described in the Methods Appendix, Section S1.1 ("The AI agents"): the agent harness, the rules and guardrails, and step-by-step instructions to reproduce the agent.

Other details are available on request from the project's data provider (see the article's Data availability statement).
